# ConciliaMei-
O software ConciliaMEI e um sistema web voltado a microempreendedores individuais (MEI) prestadores de servico, que integra a emissao de notas fiscais de servico eletronicas (NFS-e) com a conciliacao dos pagamentos efetivamente recebidos, eliminando a conferencia manual entre notas emitidas e valores pagos.
